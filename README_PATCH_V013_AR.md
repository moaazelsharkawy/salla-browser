# Salla Browser v013

هذا الباتش يصلح مسار الدفع ويحسن تجربة المطور والتحميل والايقونات

## اهم التعديلات

- استبدال النافذة البيضاء المؤقتة بصفحة تجهيز دفع حقيقية تحمل هوية Salla Browser
- فتح Hosted Checkout في نافذة جديدة كما في تعليمات Salla Shop مع الرجوع التلقائي الى طلبات المطور
- عند منع النوافذ المنبثقة يتم استخدام نفس النافذة تلقائيا بدل فشل العملية
- تحسين رسائل فشل تجهيز الدفع بدون عرض تفاصيل تقنية للمطور
- التحقق من ان رابط الدفع المعاد من المزود هو رابط Salla Shop الصحيح قبل فتحه
- اضافة مسودات دائمة لنموذج ادراج التطبيق مربوطة بحساب المطور
- حفظ تلقائي للمسودة واستعادتها عند العودة مع زر بدء من جديد
- اعادة ترتيب نموذج الادراج الى بيانات اساسية وروابط وتوفر ووصف التطبيق
- توحيد حالات التحميل بسبينر ونص مترجم
- ازالة كلمة Loading غير المترجمة من صفحة تفاصيل التطبيق
- تقليل المصطلحات التقنية في واجهات المطور العربية
- تكبير ايقونات الازرار والاقسام وشريط المتصفح
- تثبيت مقاس خلفية زر المفضلة ومنع انضغاطه باختلاف اللغة
- استمرار اخفاء القائمة السفلية في وضع فتح التطبيق ومنع اشرطة التمرير الخاصة بحاوية Salla Browser
