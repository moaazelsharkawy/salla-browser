# Salla Browser v011 Patch

هذا الباتش يكمل v010 ويضيف اصلاح مسار موافقة طلبات الادراج ونظام تعليق التطبيقات ونظام تقييم التطبيقات وتحسين لوحة الادارة والاقسام

## مهم قبل الاختبار

يجب تطبيق ملف SQL التالي على مشروع Supabase بعد رفع الباتش

`supabase/migrations/202609260020_admin_review_suspension_ratings.sql`

يمكن تطبيقه من Supabase SQL Editor او باستخدام Supabase CLI

```bash
npx supabase link --project-ref fsxiclfljotvvadstjxt
npx supabase db push
```

## ما تم تعديله

- اصلاح الموافقة على طلبات الادراج داخل معاملة واحدة لمنع تكرار slug والحالات الجزئية
- نشر التطبيق فور الموافقة وعدم بقائه draft
- منع تنفيذ الموافقة مرتين على نفس الطلب
- استعادة آمنة للحالات القديمة التي انشأت تطبيقا ولم تحدث حالة الطلب
- تحسين اسماء حقول لوحة الادارة وشرح الحقول غير الواضحة
- اختيار ايقونة القسم بصريا بدل كتابة اسم الايقونة يدويا
- اضافة وصف القسم وحالة التفعيل وترتيب الظهور بشكل واضح
- اضافة تعليق التطبيق مع سبب التعليق واعادة التفعيل
- اظهار تنبيه احترافي للمستخدم في تفاصيل التطبيق عند التعليق وتعطيل زر الفتح
- نظام تقييم من نجمة الى خمس نجوم
- تقييم واحد لكل مستخدم لكل تطبيق مع امكانية تعديل التقييم
- منع المطور من تقييم تطبيقه
- اظهار متوسط التقييم وعدد التقييمات في تفاصيل التطبيق
- ترجمة ALL الى الكل في الواجهة العربية
- فلترة طلبات الادراج حسب الحالة واخفاء الاجراءات عن الطلبات المحسومة
- تحويل خطأ apps_slug_key الى رسالة مفهومة للمدير
